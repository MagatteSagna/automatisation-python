Les règles de nettoyage visent des colonnes nommées nom, prenom et email. Une colonne prénom avec accent ne serait pas mise en format Titre.
Le contrôle des e-mails exige une colonne email. Sinon, un avertissement est enregistré et le contrôle est ignoré.
Le fichier nettoyé est toujours au format .xlsx.
Le rapport est un fichier texte.
